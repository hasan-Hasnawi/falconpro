# نسخة احتياطية - FalconPro Next.js

هذه نسخة احتياطية كاملة من مشروع FalconPro الأصلي المبني بـ Next.js + MongoDB.

## التاريخ
- تم إنشاء النسخة الاحتياطية: 17 أغسطس 2026
- الموقع يعمل بـ Next.js 15 + React 19 + TypeScript + Tailwind CSS + MongoDB

## كيفية العودة للنسخة الأصلية

1. أوقف أي سيرفر يعمل حالياً.
2. احذف أو أعد تسمية المجلد الحالي `falconpro`.
3. انسخ محتويات هذا المجلد (`falconpro-nextjs-backup`) إلى مجلد جديد باسم `falconpro`.
4. شغّل الأمر:
   ```bash
   npm install
   npm run build
   npm run start
   ```
5. تأكد من وجود ملف `.env.local` بالإعدادات الصحيحة.

## ملاحظة
- المجلدات `node_modules` و `.next` و `.git` لم يتم نسخها في النسخة الاحتياطية.
- عند العودة، يجب إعادة تثبيت الحزم عبر `npm install`.
